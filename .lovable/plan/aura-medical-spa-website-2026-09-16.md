# AURA Medical Spa Website

## Goal
Build a polished, responsive one-page website for **AURA | Medical Aesthetics & Spa** that feels calm, clinical, and luxurious while making consultation booking effortless.

## Experience
- Create a sticky, minimal header with the AURA wordmark, anchor navigation, mobile menu, and gold consultation action.
- Build an editorial hero using bespoke spa imagery, elegant serif typography, the supplied headline, and two clear treatment/support actions.
- Present all eight requested treatments in a responsive, refined card grid with distinct icons, concise descriptions, and booking actions.
- Add an editorial philosophy section with the three requested pillars and supporting clinic imagery.
- Add a guided consultation dialog with treatment, date, time, and contact fields, validation, and a clear confirmation state.
- Add a bottom-right concierge action that opens a compact support/booking choice dialog.
- Finish with a restrained footer containing sample locations, hours, contact details, and social links.

## Visual Direction
- Warm cream base, charcoal typography, antique-gold accents, and muted sage surfaces.
- Playfair Display headings paired with Plus Jakarta Sans body copy.
- Generous spacing, fine rules, subtle shadows, restrained motion, and crisp card geometry.
- Generate cohesive original wellness photography for the hero and philosophy areas rather than using remote stock imagery.

## Technical Details
- Implement the page in the existing React/TanStack Start index route with reusable local components and Lucide icons.
- Extend the existing Tailwind v4 semantic tokens in the global stylesheet; no hardcoded component colors.
- Use the existing shared Button and Dialog controls for interactive actions.
- Add complete page metadata and webfont links.
- Keep booking client-side as a polished demonstration flow; no external scheduling service or message delivery is connected.
- Validate the finished page at desktop and mobile widths, including navigation, dialogs, booking progression, and visual overlap checks.
